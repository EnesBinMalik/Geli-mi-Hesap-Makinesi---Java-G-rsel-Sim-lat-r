# Gelişmiş Hesap Makinesi - Java & Görsel Simülatör

![Gelişmiş Hesap Makinesi - Java & Görsel Simülatör — rozet](docs/rozet.svg)

> **Java · nesne yönelimli programlama** — tasarım ve geliştirme: **Enes Öztürk**

---

Java Patika 8 fonksiyonlu gelişmiş hesap makinesi, mod alma ve dikdörtgen alan/çevre hesabı, interaktif Java terminal simülatörü ve JavaPatika.java kaynak kodu. Hazırlayan: Enes Öztürk.

## Öne çıkanlar

- Sınıf ve metot yapısı, kapsülleme ve kalıtım
- Döngü, koşul ve koleksiyon kullanımı
- Konsol çıktısı ve girdi doğrulama
- Arayüzde canlı simülasyon ve kaynak kod görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |
